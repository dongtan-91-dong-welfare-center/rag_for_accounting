④계약조건의 변경
- 수정된 채권의 명목금액

| 항목 | 금액 |
| :--- | :--- |
| 채권·채무조정전 채권의 명목금액 | 100,000,000원 |
| 토지의 이전 | (10,000,000) |
| 출자전환 | (30,000,000) |
| 차감잔액 | 60,000,000원 |

이 표는 채권·채무조정 전 채권의 명목금액에서 토지 이전과 출자전환 금액을 차감하여 수정된 채권의 명목금액을 계산한 것이다.

- 미래 현금흐름 합계액이 명목금액에 미달하는 금액
  원리금의 감면을 통한 조건변경으로 인하여 채권·채무조정에 따른 약정상 정해진 미래 현금흐름의 합계금액이 채권의 명목금액에 미달할 경우에는 채권의 명목금액을 미래 현금흐름의 합계금액으로 감액하고 동액을 먼저 대손충당금과 상계하고 부족한 금액은 대손상각비로 인식

| 항목 | 금액 | 금액 |
| :--- | :--- | :--- |
| 수정된 채권의 명목금액 | | 60,000,000 |
| 미래 현금흐름의 합계액 | | |
| 원금(원금감면 20,000,000) | 40,000,000 | |
| 이자(500,000×10) | 5,000,000 | 45,000,000 |
| 감액대상금액 | | 15,000,000 |

이 표는 수정된 채권의 명목금액과 미래 현금흐름의 합계액(원금과 이자)을 비교하여 감액대상금액을 산정한 것이다.
