# 회계 말뭉치(Corpus) 다운로드 및 초기 설정 가이드

본 프로젝트는 저작권 보호를 위해 KASB 일반기업회계기준 등 기준서 원문과 파생물(전문 포함)을 저장소(Public)에 포함하지 않습니다. 
신규 기여자 및 로컬 개발 환경 설정을 위해 아래 절차를 따라 데이터를 준비해 주세요.

> [!NOTE]
> [TBD] KASB 저작권 정책 확인 필요 - 본 가이드는 로컬 개발 전용이며, 추후 서비스 공개 형태에 따른 공식 정책은 별도로 안내될 예정입니다.

## 초기화 후 첫 실행 시나리오

저장소를 처음 `clone` 한 직후, 프로젝트를 정상적으로 실행하기 위해서는 `data/` 디렉토리와 관련 파일들을 직접 준비해야 합니다.

### 1. 디렉토리 구조 생성
프로젝트 루트에서 터미널을 열고, 데이터를 저장할 디렉토리를 생성합니다.

```bash
mkdir -p data/raw
mkdir -p data/llm_parsed/cache
mkdir -p data/viz_output
```

### 2. 기준서 원본 문서 다운로드
KASB 공식 홈페이지(회계기준원)에서 기준서 원문 PDF를 직접 다운로드해야 합니다.

1. **접속**: [회계기준원 데이터베이스 (KASB)](https://db.kasb.or.kr) 에 접속합니다.
2. **검색 및 다운로드**: 
   - 일반기업회계기준 기준서 제1장 ~ 제33장
   - 보험업회계처리준칙 등 필요한 추가 문서
3. **저장 위치**: 다운로드한 모든 `.pdf` 파일은 `data/raw/` 폴더 내에 저장합니다.

> [!IMPORTANT]
> 원본 파일들은 파이프라인(E2E, Indexing 등) 실행을 위한 필수 입력 파일입니다. 이 과정이 생략될 경우 데이터 파이프라인에서 오류가 발생합니다.

### 3. 파생 데이터 생성 (선택 사항)
본 프로젝트에 포함된 파싱 및 변환 스크립트를 사용하여 텍스트 청크나 마크다운 등을 생성합니다.
(자세한 스크립트 실행 방법은 `README.md` 및 파이프라인 가이드를 참조하세요.)

- **실행 결과물**: `data/chunks.json`, `data/llm_parsed/`, `data/회계_sample.*`, `dataset_accounting_sample.json` 등은 스크립트 실행 후 자동으로 생성됩니다.
