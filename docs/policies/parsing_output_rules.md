# 파싱 산출물(llm_parsed) 규칙 정의

> **한 줄 요약(BLUF):** `data/llm_parsed/*.md`가 파싱의 **정본**이며, 원본 PDF와의 차이 중 **의도된 것(취소선 폐지 조문 제외 등)** 과 **결함(누락·환각·오타)** 을 구분하는 기준을 정의한다. `cache/`·`pages/`는 중간 산출물이므로 검증 기준으로 쓰지 않는다.
>
> 용어: 이 문서에서 '정본'은 `data/llm_parsed/<문서명>.md`(최종 md)를 가리킨다. 공통 용어는 [용어 사전](../README.md) 참조.

---

## 1. 페이지 마커 시맨틱

- 정본의 `<!-- page N -->` 마커는 **PDF 물리 N페이지**(하단 `- N -` 표기)와 1:1 매핑된다.
- 문장이 페이지 경계에서 끊기면 원문 그대로 끊어 적는다(다음 마커 뒤에서 이어짐). 페이지 간 문장 병합은 허용하되, 그 경우 내용이 인접 마커 아래 존재하면 누락이 아니다.

`근거:` 청킹·조항 로케이터가 페이지 마커를 위치 기준으로 쓰므로, 마커가 물리 페이지와 어긋나면 인용 출처가 틀어진다.

## 2. 취소선(폐지 조문) 제외 규칙

- 원본 PDF에서 **본문에 취소선이 그어진 조문은 폐지된 규정이므로 정본에 싣지 않는다.**
- 취소선 없이 남은 대체 고지(예: `[기업회계기준서 제8호 "유가증권"으로 대체(2002. 1. 25)]`)는 유지한다.
- 따라서 페이지 마커는 있으나 본문이 비었거나 대체 고지만 있는 페이지는 **누락이 아니라 정상**이다.

`근거:` 폐지 조문을 실으면 현행 기준이 아닌 조항이 검색·인용되어 오답을 유발한다(2026-07-04 보험업회계처리준칙 p4~6·p12~15 시각 판독으로 확정).

## 3. 허용되는 '얇은 페이지' 사유

아래에 해당하면 본문이 짧아도 결함이 아니다. 커버리지 검증(§5) 시 오탐 처리한다.

| 사유 | 예 |
|---|---|
| 표지·의결문 | 제8장 p1 |
| 목차 | 제26장 p2~3 |
| 취소선 폐지 조문(§2) | 보험업회계처리준칙 p4~6, p12~15 |
| 원문 자체가 짧음 | 제24장 p5 (목록 파편 38자) |
| 인접 페이지에 병합 | 일반기업회계기준_시행일_및_경과규정 p11 |

## 4. 검증 방법과 최근 결과

- **커버리지**: PDF 페이지 수(pikepdf) ↔ 정본 마커 집합 대조. 마커 없거나 본문 50자 미만이면 의심 → §2·§3 사유로 설명되는지 확인.
- **내용 대조**: 의심 페이지는 PDF 원문(pdfminer) 고유 문구를 정본에 grep해 존재 확정.
