# ADR-0002 — 임베딩 모델: nlpai-lab/KURE-v1 (자체호스팅)

> **한 줄 요약(BLUF):** 한국어 회계 도메인 검색을 위해 임베딩을 **KURE-v1**(bge-m3 기반, 1024차원, MIT)로 자체호스팅한다. 관리형 API 대신 자체호스팅을 골라 인덱싱·검색이 한 함수를 공유하고, 차원·모델 불일치를 구조적으로 없앤다.

- **Status:** Accepted
- **Date:** 2026-06-27 (소급)
- **근거:** #93(모델 확정) · **관련:** #117·#150(대량 적재 OOM 완화)

## 1. 왜 (Context)
- 회계기준 질의는 한국어 전문 용어가 많아, 범용·영어 위주 임베딩으로는 의미 검색 품질이 떨어진다.
- 인덱싱(FUNC-003)과 검색(FUNC-005)이 서로 다른 모델·차원을 쓰면 벡터가 호환되지 않는다. 한 곳에서 고정해야 한다.

## 2. 무엇을 골랐나 (Decision)
- `nlpai-lab/KURE-v1`(bge-m3 기반, 1024차원, MIT)를 **자체호스팅**한다. 모델·차원 값은 `src/utils/config.py`(`EMBEDDING_MODEL`·`EMBEDDING_DIM`)가 정본.
- 인덱싱·검색이 `src/utils/embedding.py`의 `embed_texts()`를 **공유**한다 → 모델·차원 불일치가 구조적으로 발생하지 않는다.

**선정 근거 (대안 대비)** — 여러 한국어 임베딩 중 KURE-v1을 고른 기준:
- **한국어 검색 성능**: bge-m3 기반 한국어 특화로 회계 도메인 용어에 적합.
- **라이선스**: MIT — 자유 사용·재배포.
- **비용**: 자체호스팅은 추가 과금이 0이다(관리형 API는 사용량 과금). *정량 비용·성능 비교는 미기록* — 있으면 #93·측정 문서로 링크한다.

**탈락 대안**: 관리형 임베딩 API(OpenAI·Voyage·Cohere 등)·타 한국어 오픈모델. 관리형 재검토 여지는 #151(임베딩 실행 위치·관리형 API)로 잇는다.

**리랭커 정합(미래)**: 현행 리랭커는 영어 계열(`RERANK_MODEL`, config)이고 기본 비활성(`USE_RERANKER`)이다. bge-m3 계열 한국어 리랭커(`bge-reranker-v2-m3`)와의 정합은 #159(한국어 리랭커 교체) 이후 실현될 미래 사항이다.

## 3. 결과(영향) (Consequences)
- (+) 한국어 도메인 적합도가 높고, 차원 정합이 구조적으로 보장되며, 외부 API 비용·의존이 없다.
- (−) GPU가 필요하다 — Docker on Mac은 MPS 패스스루가 안 돼 **호스트 네이티브 실행**이 필요하다(`POSTGRES_HOST=localhost`).
- (−) 대량 적재 시 CPU 포화·메모리 누적 OOM 위험이 있다 → 완화·배치/스레드 설정은 #117·#150과 config로 다룬다.
