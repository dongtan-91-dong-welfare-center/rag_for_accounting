# 제7장 재고자산 온톨로지 설계안

대상 원문: `data/llm_parsed/제7장_재고자산(제33장_제정_반영).md`

공통 노드, 공통 엣지, 필수 속성, part taxonomy, `extraction_status`, 실패 조건 중심 품질 기준은 `docs/ontology/common_schema.md`를 따른다. 이 문서는 제7장 특화 Rule과 추출 패턴만 정의한다.

이 문서는 제7장을 기준으로 온톨로지를 만들 때의 장별 추출 기준이다. 제7장은 재고자산의 범위, 취득원가 구성, 원가결정방법, 저가법, 비용 인식, 표시와 공시가 핵심이다. 단순히 재고자산 개념만 연결하면 원가 포함 여부, 평가손실, 환입, 공시 요구를 답할 수 없으므로 Rule 중심으로 모델링해야 한다.

## 1. 핵심 방향

제7장은 다음 질문에 답할 수 있어야 한다.

- 어떤 자산이 재고자산에 포함되고 어떤 항목은 적용범위에서 제외되는가?
- 재고자산의 장부금액은 취득원가와 시가 중 무엇으로 결정되는가?
- 매입원가, 제조원가, 기타원가에는 어떤 원가가 포함되거나 제외되는가?
- 고정제조간접원가와 변동제조간접원가는 어떤 기준으로 배부하는가?
- 개별법, 선입선출법, 가중평균법, 후입선출법, 표준원가법, 소매재고법은 어떤 조건에서 적용되는가?
- 저가법은 언제 적용하고, 시가와 순실현가능가치는 어떻게 판단하는가?
- 재고자산평가손실, 환입, 감모손실은 어떻게 인식·분류하는가?
- 재고자산 분류와 주석 공시는 무엇을 요구하는가?
- 실무지침은 어느 본문 조항을 보충하는가?

## 5. 주요 추출 패턴

### 5.1 적용범위와 제외

7.2는 `ScopeRule`로 만들고 제외 항목을 `EXCLUDES`로 연결한다.

- `APPLIES_TO`: ScopeRule -> 재고자산
- `EXCLUDES`: ScopeRule -> 건설형 공사계약 진행중인 건설공사
- `EXCLUDES`: ScopeRule -> 금융상품
- `EXCLUDES`: ScopeRule -> 생물자산 및 수확시점 농림어업 수확물
- `EXCLUDES`: ScopeRule -> 온실가스 배출권

제외 항목은 관련 장이 있으면 `REFERENCES`로 연결한다. 금융상품은 제6장, 차입원가 관련 실무지침은 제18장, 수익인식 관련 재고 포함 판단은 제16장과 연결한다.

### 5.2 장부금액과 저가법

7.4는 기본 측정 규칙과 예외 규칙으로 나눈다.

- 기본 `MeasurementRule`: 재고자산 장부금액은 취득원가
- 예외 `LowerOfCostAndMarketRule`: 시가가 취득원가보다 낮은 경우 시가를 장부금액으로 함
- `MEASURED_BY`: 재고자산 -> 취득원가, 시가
- `HAS_EXCEPTION`: 취득원가 측정 규칙 -> 저가법 규칙

7.16~7.19는 저가법 세부 규칙이다.

- `HAS_CONDITION`: 손상, 장기체화, 진부화, 완성·판매원가 상승
- `MEASURED_BY`: 저가법 -> 순실현가능가치
- `HAS_EXCEPTION`: 원재료 저가법 미적용 조건
- `RECOGNIZES_AS`: 평가손실 -> 재고자산 차감계정 및 매출원가
- `RECOGNIZES_AS`: 평가손실 환입 -> 매출원가 차감

### 5.3 원가 포함과 제외

7.5~7.11은 원가 구성 규칙이다.

- `INCLUDES_COST`: 취득원가 -> 매입원가, 제조원가, 정상적으로 발생한 기타원가
- `INCLUDES_COST`: 매입원가 -> 매입금액, 매입운임, 하역료, 보험료
- `EXCLUDES_COST`: 매입원가 -> 할인, 에누리, 유사 차감 항목
- `INCLUDES_COST`: 제조원가 -> 직접재료원가, 직접노무원가, 제조간접원가 배부액
- `EXCLUDES_COST`: 재고자산 원가 -> 비정상 낭비, 불필요한 보관비용, 관리간접원가, 판매원가
- `RECOGNIZES_IN`: 제외 원가 -> 발생기간 비용

실7.11처럼 소비세가 원가에 포함되지 않는 원칙과 중간납부자 예외는 `ExceptionRule`로 분리한다.

### 5.4 배부 규칙

7.6, 7.8, 7.9는 원가 배부 규칙이다.

- 일괄구입 재고자산: 총매입원가를 공정가치 비율로 배분
- 고정제조간접원가: 정상조업도 기준 배부
- 실제조업도가 정상조업도와 유사한 경우 실제조업도 사용 가능
- 비정상적으로 낮은 조업도나 유휴설비로 단위당 배부액 증가 금지
- 공통원가: 상대적 판매가치 기준 배부, 더 합리적이면 생산량기준 사용 가능

배부 기준은 `AllocationBasis` 노드로 만들어 `MEASURED_BY` 또는 `ALLOCATED_BY` 관계로 둔다.

### 5.5 원가결정방법

7.12~7.15는 원가흐름 가정과 편의적 원가측정방법이다.

- 개별법: 상호 교환 불가능하거나 특정 프로젝트별 생산 품목
- FIFO/가중평균법/LIFO: 7.12가 적용되지 않는 재고자산
- 동일한 성격과 용도의 재고자산에는 동일 방법 적용
- 표준원가법/소매재고법: 실제 원가와 유사한 경우 편의상 사용
- 소매재고법: 원칙적으로 유통업종, 예외적 사용 시 정당한 이유와 합리적 근거 공시

후입선출법은 공시 요구가 강하므로 `CostFormulaRule`과 `DisclosureRule`을 반드시 연결한다.

### 5.6 비용 인식과 분류

7.20은 인식과 분류가 함께 있으므로 분리한다.

- 판매된 재고자산은 수익 인식 기간에 매출원가로 인식
- 평가손실은 재고자산 차감계정으로 표시하고 매출원가에 가산
- 정상 감모손실은 매출원가
- 비정상 감모손실은 영업외비용

감모손실은 `InventoryShrinkageLoss` 개념으로 만들고 정상/비정상 조건에 따라 분류한다.

### 5.7 표시와 공시

7.21~7.24는 표시와 공시 규칙이다.

- 재고자산은 총액 또는 상품, 제품, 재공품, 원재료, 소모품 등으로 표시
- 서비스업 재고는 재공품으로 분류 가능
- 원가결정방법, 총액 보고 내용, 저가법 적용기준과 평가 내용, 담보 제공 재고자산 공시
- LIFO 사용 시 재무상태표 금액과 FIFO/평균법 저가법 평가액 차이 공시
- 기초재고청산 시 평균취득단가 기준 금액과 장부상 원가 차액 공시

## 6. 보충 자료 연결

- `실7.1~실7.2`: 재고자산 포함 범위와 고정자산 분류 판단을 7.3에 `SUPPLEMENTS` 연결
- `실7.3`: 연불조건 원자재 수입 이자 처리. 7.6 및 제18장에 `REFERENCES` 연결
- `실7.4`, `실7.12`, `실7.13`: 제조원가와 기타원가 포함 판단을 7.7에 `SUPPLEMENTS` 연결
- `실7.5`: 미착상품, 시송품, 적송품, 저당상품, 반품률 높은 상품, 할부판매상품의 재고 포함 판단을 7.3 및 제16장에 연결
- `실7.7~실7.9`: 순실현가능가치 추정과 항목별/통합 평가 판단을 7.17~7.18에 연결
- `실7.10`: 가중평균법 세부 적용을 7.13에 연결
- `실7.11`: 소비세 원가 포함 예외를 7.6에 연결

## 7. 품질 점검 기준

- 7.2의 네 가지 제외 항목은 모두 `EXCLUDES` 관계로 표현되어야 한다.
- 7.4의 취득원가 원칙과 저가법 예외는 별도 Rule로 분리해야 한다.
- 원가 포함 항목과 원가 제외 항목은 각각 `INCLUDES_COST`, `EXCLUDES_COST` 또는 동등한 의미 관계로 구분해야 한다.
- 7.8의 정상조업도, 실제조업도, 유휴설비 관련 조건은 배부 규칙의 조건으로 남겨야 한다.
- 7.12~7.15의 원가결정방법은 방법 개념과 적용 조건을 함께 가져야 한다.
- 저가법 관련 조항은 `LowerOfCostAndMarketRule` 또는 `MeasurementRule`을 가져야 한다.
- 공시 조항 7.22~7.24는 `DisclosureItem`으로 항목을 분리해야 한다.
- 실7.*는 본문 Rule을 대체하지 않고 `SUPPLEMENTS`로 연결해야 한다.

## 8. 산출물 초점

제7장 산출물은 `재고자산인지 판단 -> 원가에 포함할지 판단 -> 어떤 원가결정방법을 적용할지 판단 -> 저가법과 손실/환입 처리 -> 표시·공시`의 흐름을 질의 가능하게 만드는 것이 핵심이다.
