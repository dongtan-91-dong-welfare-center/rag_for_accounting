# 제1장 목적, 구성 및 적용 온톨로지 설계안

대상 원문: `data/llm_parsed/제1장_목적__구성_및_적용(수정목록_19-1_반영).md`

공통 노드, 공통 엣지, 필수 속성, part taxonomy, `extraction_status`, 실패 조건 중심 품질 기준은 `docs/ontology/common_schema.md`를 따른다. 이 문서는 제1장 특화 Rule과 추출 패턴만 정의한다.

이 문서는 제1장을 기준으로 온톨로지를 만들 때의 장별 추출 기준이다. 제1장은 조항 수가 적지만 전체 회계기준 온톨로지의 최상위 적용범위, 기준 구성, 해석 원칙을 정한다. 따라서 단순 설명 문장으로 버리지 말고 전역 메타 규칙으로 모델링해야 한다.

## 1. 핵심 방향

제1장은 다음 질문에 답할 수 있어야 한다.

- 이 회계기준의 목적은 무엇인가?
- 기준서는 어떤 문서 파트로 구성되는가?
- 어떤 기업이 이 기준을 적용해야 하는가?
- 한국채택국제회계기준을 적용하지 않는 기업과 외부감사 대상 기업의 관계는 무엇인가?
- 중요하지 않은 항목에 대한 적용 예외는 어떻게 표현되는가?
- 기준 해석 시 어떤 배경 자료와 개념체계를 함께 참조해야 하는가?

제1장은 `Chapter -> Clause -> Rule` 구조를 최소 단위로 유지하되, 추출된 규칙은 모든 장에서 참조 가능한 `GlobalRule` 성격으로 관리한다.

## 2. 문서 파트 분리

| part | 존재 여부 | 범위 | 역할 |
|---|---|---|---|
| `main` | present | 1.1~1.4 | 기준의 목적, 구성, 적용범위, 해석 원칙 |
| `terms` | absent | 없음 | 별도 용어정의 part 없음 |
| `application_guidance` | absent | 없음 | 1.2에서 구성요소로 언급되지만 제1장 자체에는 별도 part 없음 |
| `basis_for_conclusions` | absent | 없음 | 1.2/1.4에서 구성요소로 언급되지만 제1장 자체에는 별도 part 없음 |
| `practical_guidance` | absent | 없음 | 1.2/1.4에서 구성요소로 언급되지만 제1장 자체에는 별도 part 없음 |
| `example` | absent | 없음 | 1.2/1.4에서 구성요소로 언급되지만 제1장 자체에는 별도 part 없음 |

제1장에는 별도 실무지침이나 사례가 없으므로 모든 조항은 `main`으로 둔다. 다만 이후 장의 `basis_for_conclusions`, `practical_guidance`, `example`을 해석할 때 제1장의 구성 규칙을 참조해야 한다.

## 3. 핵심 개념

| 개념군 | 예시 |
|---|---|
| 기준 체계 | 일반기업회계기준, 한국채택국제회계기준, 회계기준위원회, 기업회계기준서 |
| 적용 대상 | 외부감사대상기업, 한국채택국제회계기준 미적용 기업, 일반목적 재무보고 기업 |
| 문서 구성 | 본문기준, 적용보충기준, 부록, 결론도출근거, 실무지침, 사례 |
| 해석 기준 | 재무회계개념체계, 해석 배경, 경제적 실질 |
| 예외 개념 | 중요성, 중요하지 않은 항목, 적용 생략 |

개념 노드는 전역으로 관리하고, 제1장에서는 해당 개념을 정의하거나 전체 기준에 적용하는 규칙을 연결한다.

## 4. Rule 유형

| rule_type | 적용 조항 | 설명 |
|---|---|---|
| `PurposeRule` | 1.1 | 기준 제정 목적과 전체 문서의 목적을 표현 |
| `CompositionRule` | 1.2 | 기준서가 어떤 문서 파트로 구성되는지 표현 |
| `ScopeRule` | 1.3 | 기준 적용 대상 기업과 선택 적용 가능 대상을 표현 |
| `ExceptionRule` | 1.3 | 중요하지 않은 항목에 대한 적용 예외 |
| `InterpretationRule` | 1.4 | 기준 해석 시 고려해야 할 배경과 개념체계 |

## 5. 주요 추출 패턴

### 5.1 목적 규칙

1.1은 `PurposeRule`로 만든다.

- `HAS_RULE`: 제1장 또는 기준서 -> 목적 규칙
- `APPLIES_TO`: 목적 규칙 -> 일반기업회계기준
- `REFERENCES`: 목적 규칙 -> 일반목적 재무보고 목적

### 5.2 구성 규칙

1.2는 `CompositionRule`로 만들고 기준서의 문서 파트를 독립 노드로 둔다.

- `HAS_PART`: 일반기업회계기준 -> 본문기준
- `HAS_PART`: 일반기업회계기준 -> 적용보충기준
- `HAS_PART`: 일반기업회계기준 -> 부록, 결론도출근거, 실무지침, 사례
- `SUPPLEMENTS`: 적용보충기준/실무지침/사례 -> 본문기준
- `BASIS_FOR`: 결론도출근거 -> 관련 본문기준

### 5.3 적용범위와 중요성 예외

1.3은 최소 두 개의 규칙으로 나눈다.

- `ScopeRule`: 외부감사대상기업 중 한국채택국제회계기준을 적용하지 않는 기업에 적용
- `ExceptionRule`: 중요하지 않은 항목은 이 기준을 적용하지 않을 수 있음

관계는 다음처럼 표현한다.

- `APPLIES_TO`: ScopeRule -> 외부감사대상기업
- `EXCLUDES`: ScopeRule -> 한국채택국제회계기준 적용 기업
- `HAS_EXCEPTION`: ScopeRule -> 중요성 예외 규칙
- `HAS_CONDITION`: 중요성 예외 규칙 -> 중요하지 않은 항목

### 5.4 해석 규칙

1.4는 `InterpretationRule`로 만들고, 모든 장의 질의응답에서 참조 가능한 전역 해석 근거로 둔다.

- `REFERENCES`: InterpretationRule -> 재무회계개념체계
- `REFERENCES`: InterpretationRule -> 기준 제정 배경
- `APPLIES_TO`: InterpretationRule -> 전체 기준서

## 6. 품질 점검 기준

- 1.1~1.4 네 개 조항이 모두 Rule 노드로 변환되어야 한다.
- 1.3의 적용범위와 중요성 예외는 하나의 문장 안에 있어도 별도 규칙으로 분리해야 한다.
- 기준 문서 구성 요소는 단순 텍스트가 아니라 `DocumentPart` 노드로 만든다.
- `중요하지 아니한 항목`은 일반 개념이 아니라 예외 조건으로 연결한다.
- 1.4의 해석 규칙은 이후 모든 장에서 `REFERENCES` 가능한 전역 규칙으로 관리한다.

## 7. 산출물 초점

제1장 산출물은 개념 수보다 전역 메타 규칙의 정확성이 중요하다. 이후 장별 온톨로지 생성 시 문서 파트 분리, 적용범위 판단, 중요성 예외, 해석 근거 연결의 기준으로 재사용해야 한다.
