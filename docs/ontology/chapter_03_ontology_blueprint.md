# 제3장 재무제표의 작성과 표시2(금융업) 온톨로지 설계안

대상 원문: `data/llm_parsed/제3장_재무제표의_작성과_표시2(금융업)_(2022년_개정_반영).md`

공통 노드, 공통 엣지, 필수 속성, part taxonomy, `extraction_status`, 실패 조건 중심 품질 기준은 `docs/ontology/common_schema.md`를 따른다. 이 문서는 제3장 특화 Rule과 추출 패턴만 정의한다.

이 문서는 제3장을 기준으로 온톨로지를 만들 때의 장별 추출 기준이다. 제3장은 제2장의 일반 표시 기준을 금융업에 맞게 특수화한 장이다. 따라서 제2장 구조를 재사용하되 금융회사 전용 분류, 표시, 상계, 공시 규칙을 별도 Rule로 만들어야 한다.

## 1. 핵심 방향

제3장은 다음 질문에 답할 수 있어야 한다.

- 금융업 재무제표 표시 기준은 어떤 기업과 재무제표에 적용되는가?
- 금융회사의 재무상태표 자산과 부채는 어떤 항목 체계로 분류되는가?
- 금융회사의 손익계산서 수익과 비용은 어떤 항목으로 표시되는가?
- 금융업 현금흐름표의 영업, 투자, 재무활동 분류는 일반기업과 어떻게 다른가?
- 금융회사 표시 기준과 제2장 일반 표시 기준, 제6장 금융상품 기준은 어떤 관계인가?
- 금융업 사례와 양식은 어느 표시 규칙을 설명하는가?

제3장은 측정 장이 아니라 표시 장이다. 금융상품이 많이 나오더라도 기본 Rule은 `PresentationRule`, `ClassificationRule`, `DisclosureRule`로 만든다.

## 2. 문서 파트 분리

| part | 존재 여부 | 범위 | 역할 |

| `terms` | absent | 없음 | 금융업과 금융회사 정의는 3.1 main의 DefinitionRule로 처리 |
| `application_guidance` | absent | 없음 | 별도 적용보충기준 없음 |
| `basis_for_conclusions` | present | 결3.* | 금융업 표시 체계의 근거 |

| 개념군 | 예시 |
|---|---|
| 적용 대상 | 금융회사, 금융업, 은행업, 보험업, 금융투자업, 여신전문금융업 |
| 재무제표 | 금융회사 재무상태표, 금융회사 손익계산서, 금융회사 현금흐름표 |

| 손익 항목 | 영업수익, 영업비용, 이자수익, 이자비용, 수수료수익, 수수료비용, 유가증권평가손익, 대출채권손상 |

## 5. 주요 추출 패턴

### 5.1 제2장과의 관계

제3장은 제2장 일반 표시 기준의 특수 장이다.

- `SPECIALIZES`: 제3장 Rule -> 제2장 재무제표 표시 Rule
- `APPLIES_TO`: 제3장 Rule -> 금융회사
- `REFERENCES`: 금융상품 관련 항목 -> 제6장 금융자산·금융부채

제3장에 명시된 특수 표시 기준이 있으면 제2장 일반 규칙보다 우선하는 `ScopeRule`, `ExceptionRule` 또는 `OVERRIDES` 관계를 둔다.

### 5.2 금융업 재무상태표 표시

3.3~3.6은 금융회사 재무상태표 구조와 표시 원칙으로 만든다.

- `HAS_RULE`: 금융회사 재무상태표 -> 표시 규칙
- `CLASSIFIES_AS`: 자산/부채 -> 금융업 전용 항목
- `HAS_CONDITION`: 정형화된 유가증권 거래, 타인 보유 유가증권 등
- `DISCLOSES`: 제3자 보유 유가증권 등 주석 공시

### 5.3 자산과 부채 분류

3.7~3.15는 계정과목 사전이 아니라 분류 규칙이다.

- 현금및예치금, 유가증권, 대출채권 등은 `AccountingItem`으로 만든다.
- 각 항목은 `FinancialAssetClassificationRule` 또는 `FinancialLiabilityClassificationRule`에 의해 분류된다.
- 제6장 측정 개념과 혼동하지 않도록, 공정가치나 손상은 본문에 직접 규정된 경우에만 측정 관련 관계를 둔다.

### 5.4 손익계산서와 현금흐름표

3.16~3.18은 금융업 손익 항목의 표시 규칙이다.

- `CLASSIFIES_AS`: 금융업 손익 -> 영업수익/영업비용
- `HAS_PART`: 영업수익 -> 이자수익, 수수료수익, 유가증권 관련 손익 등
- `HAS_PART`: 영업비용 -> 이자비용, 대출채권 관련 손상, 판매관리비 등

3.20~3.21은 금융업 현금흐름 분류 규칙으로 만든다.

- `CLASSIFIES_AS`: 금융업 현금흐름 -> 영업활동/투자활동/재무활동
- `HAS_EXCEPTION`: 순액 표시가 허용되는 경우

## 6. 보충 자료 연결

- `결3.*`: 금융업 별도 표시 기준을 둔 이유로 `BASIS_FOR` 연결
- `소3.*`: `MinorityOpinion` 노드로 만들고 관련 결론도출근거에 `REFERENCES` 연결
- `실3.*`: 자산, 부채, 손익 항목 분류 규칙에 `SUPPLEMENTS` 연결
- 사례 1, 사례 2: 재무상태표 및 손익계산서 양식에 `ILLUSTRATES` 연결

## 7. 품질 점검 기준

- 제3장의 금융업 항목을 제2장 일반 항목으로 덮어쓰지 않아야 한다.
- 금융상품 용어가 나오더라도 제3장에서는 표시·분류 중심으로 추출해야 한다.
- 정형화된 유가증권 거래, 타인 보유 유가증권, 순액 표시 조건은 별도 조건/예외 관계로 표현해야 한다.
- 소수의견은 본문 규칙으로 오인하지 않고 별도 파트로 관리해야 한다.
- 사례 양식은 본문 규칙의 예시로만 연결한다.

## 8. 산출물 초점

제3장 산출물은 금융업 표시 계층을 만드는 것이 핵심이다. 제2장의 일반 재무제표 구조를 재사용하면서 금융회사 전용 항목과 표시 예외를 분리해야, 이후 금융상품 장과 금융업 공시 질의에서 충돌이 줄어든다.
