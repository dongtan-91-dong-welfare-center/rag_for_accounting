# 제2장 재무제표의 작성과 표시1 온톨로지 설계안

대상 원문: `data/llm_parsed/제2장_재무제표의_작성과_표시1(2023년_개정_반영_수정목록_19-1_반영).md`

공통 노드, 공통 엣지, 필수 속성, part taxonomy, `extraction_status`, 실패 조건 중심 품질 기준은 `docs/ontology/common_schema.md`를 따른다. 이 문서는 제2장 특화 Rule과 추출 패턴만 정의한다.

이 문서는 제2장을 기준으로 온톨로지를 만들 때의 장별 추출 기준이다. 제2장은 일반기업 재무제표 표시의 기본 장이므로 `표시`, `분류`, `비교표시`, `상계`, `주석공시` 규칙을 Rule 중심으로 세분화해야 한다.

## 1. 핵심 방향

제2장은 다음 질문에 답할 수 있어야 한다.

- 일반기업 재무제표는 어떤 재무제표와 주석으로 구성되는가?
- 계속기업 가정, 공정표시, 중요성, 구분표시 원칙은 어떤 조건에서 적용되는가?
- 재무상태표 항목은 유동/비유동, 자산/부채/자본으로 어떻게 분류되는가?
- 손익계산서, 현금흐름표, 자본변동표는 어떤 구조와 표시 원칙을 갖는가?
- 비교재무제표, 표시방법 변경, 재분류는 언제 필요하고 무엇을 공시해야 하는가?
- 본문, 결론도출근거, 실무지침, 사례 양식은 어떻게 연결되는가?

제2장은 `PresentationRule`과 `ClassificationRule`을 중심으로 만들고, 표시 원칙과 계정 분류를 같은 관계로 뭉개지 않는다.

## 2. 문서 파트 분리

| part | 존재 여부 | 범위 | 역할 |
|---|---|---|---|
| `main` | present | 2.1~2.90 | 재무제표 작성과 표시의 본문 기준 |
| `terms` | absent | 없음 | 별도 용어정의 part 없음. 재무제표 구성 등 정의성 문장은 main의 DefinitionRule로 처리 |
| `application_guidance` | absent | 없음 | 별도 적용보충기준 없음 |
| `basis_for_conclusions` | present | 결2.* | 규정 이유와 대안 검토 |
| `practical_guidance` | present | 실2.* | 항목 분류, 양식, 실무 적용 |
| `example` | present | 적용사례, 사례 및 양식 | 재무제표 표시 형식 예시 |

모든 `결2.*`, `실2.*`, 사례는 본문 규칙을 대체하지 않는다.
`결2.*`는 `BASIS_FOR`로 연결한다.
`실2.*`는 `SUPPLEMENTS`, 사례는 `ILLUSTRATES`로 연결한다.

| 작성 원칙 | 계속기업, 공정표시, 중요성, 구분표시, 통합표시, 비교표시, 표시 계속성 |

## 4. Rule 유형

| rule_type | 적용 범위 | 설명 |
|---|---|---|
| `ScopeRule` | 2.2~2.3 | 제2장의 적용범위와 다른 장 우선 적용 관계 |
| `StatementStructureRule` | 2.4, 2.17, 2.44, 2.58, 2.74, 2.82 | 재무제표 구성과 최소 표시 구조 |
| `GoingConcernRule` | 2.5 | 계속기업 평가와 불확실성 공시 |
| `PresentationRule` | 2.6~2.16, 각 재무제표 표시 조항 | 공정표시, 구분표시, 비교표시, 표시 계속성 |
| `ClassificationRule` | 2.18~2.40, 실무지침 | 유동/비유동 및 항목 분류 |
| `OffsettingRule` | 2.41~2.43, 2.57 | 자산/부채 및 수익/비용 상계 금지와 예외 |
| `CashFlowClassificationRule` | 2.60~2.73 | 현금흐름 활동별 분류와 표시 |
| `DisclosureRule` | 2.5, 2.8, 2.14, 2.82~2.90 | 주석 공시 요구사항 |

## 5. 주요 추출 패턴

### 5.1 재무제표 구성

2.4는 `StatementStructureRule`로 만들고 재무제표 구성 요소를 독립 노드로 둔다.

- `HAS_PART`: 재무제표 -> 재무상태표, 손익계산서, 현금흐름표, 자본변동표, 주석
- `HAS_RULE`: 제2장 -> 재무제표 구성 규칙
- `APPLIES_TO`: 구성 규칙 -> 일반기업 재무제표

### 5.2 일반 표시 원칙

2.5~2.16은 원칙별 Rule로 분리한다.

- 계속기업 평가는 `GoingConcernRule`로 만들고 불확실성 공시는 `DisclosureRule`로 연결한다.
- 공정표시와 기준 준수 공시는 별도 `PresentationRule`, `DisclosureRule`로 나눈다.
- 중요성 기준에 따른 구분표시와 통합표시는 `HAS_CONDITION`으로 조건을 남긴다.
- 비교표시와 표시 계속성은 재분류가 필요한 경우 `HAS_EXCEPTION` 또는 `HAS_CONDITION`으로 표시한다.

### 5.3 재무상태표 분류

2.18~2.40은 자산과 부채 분류 규칙으로 세분화한다.

- `CLASSIFIES_AS`: ClassificationRule -> 유동자산/비유동자산/유동부채/비유동부채
- `HAS_CONDITION`: 정상영업주기, 보고기간 후 12개월, 결제권리, 차입약정 위반 등
- `HAS_EXCEPTION`: 정상영업주기 기준, 재융자 약정, 채무불이행 유예 조건

특히 차입약정 위반, 재융자, 보고기간 후 사건과 연결되는 문장은 조건과 예외를 분리해야 한다.

### 5.4 손익계산서와 현금흐름표

손익계산서 조항은 `PresentationRule`과 `OffsettingRule`로 나눈다. 수익과 비용의 총액 표시 원칙, 중단영업이나 특별손익 표시 금지 여부가 나오면 독립 규칙으로 둔다.

현금흐름표 조항은 `CashFlowClassificationRule`을 우선 사용한다.

- `CLASSIFIES_AS`: 현금흐름 -> 영업활동/투자활동/재무활동
- `HAS_CONDITION`: 직접법, 간접법, 순액 표시 허용 조건
- `DISCLOSES`: 현금및현금성자산 구성, 비현금거래 등

### 5.5 주석 공시

2.82~2.90은 `DisclosureRule`로 만들고 공시 항목을 `DisclosureItem` 노드로 분리한다.

- 주요 회계정책
- 추정 불확실성
- 재무제표 승인일과 승인권자
- 배당 정보
- 재분류 및 표시 변경 사유

## 6. 보충 자료 연결

- `결2.*`: 관련 본문 Rule에 `BASIS_FOR`로 연결한다.
- `실2.*`: 본문 표시/분류 규칙에 `SUPPLEMENTS`로 연결한다.
- 사례와 양식: 관련 재무제표 구조 규칙에 `ILLUSTRATES`로 연결한다.

## 7. 품질 점검 기준

- 재무제표 구성 요소가 모두 `Statement` 또는 `Disclosure` 개념으로 생성되어야 한다.
- 표시 원칙과 항목 분류를 모두 `RELATED_TO`로 처리하지 말고 Rule 유형을 분리해야 한다.
- `다만`, `예외적으로`, `조건을 충족하는 경우` 문장은 `HAS_EXCEPTION` 또는 `HAS_CONDITION`으로 표현해야 한다.
- 결론도출근거와 실무지침이 본문 규칙처럼 잘못 승격되지 않아야 한다.
- 비교표시, 표시 변경, 재분류 관련 공시가 누락되지 않아야 한다.

## 8. 산출물 초점

제2장 산출물은 전체 재무제표 표시 온톨로지의 기본 뼈대가 된다. 이후 금융업 표시, 연결재무제표, 개별 계정 장의 표시·공시 규칙이 제2장의 재무제표 구조 노드를 재사용하도록 설계한다.
